# AI Office · этап 1

Самостоятельный локальный пиксельный офис для восьми постоянных работников AI-команды.

## Запуск в Windows

Требуется Node.js 22.12+ (проверено на 24.18) и npm.

Откройте PowerShell в папке проекта:

```powershell
npm install
npm run dev
```

Откройте адрес, напечатанный Vite, обычно http://127.0.0.1:5173.
Также можно дважды нажать `START.cmd`. Остановка — Ctrl+C в открытом окне.

## Что проверить

- В комнате ровно 8 сотрудников; каждый со своим столом, цветом, персонажем и ролью.
- Нажатие на стол или Enter/Space открывает задачу и прогресс справа.
- Mock-события меняют состояния каждые 2,6 секунды, журнал ограничен 80 событиями.
- Пауза останавливает события и анимации, продолжение возобновляет их; сброс возвращает исходные данные.
- Вкладка «Задачи» открывает восемь задач, нажатие возвращает к исполнителю.
- Activity можно фильтровать по сотруднику или ошибкам.
- На телефоне сцена прокручивается вбок, панели расположены ниже.

При перезагрузке демонстрация начинается заново. Данные не сохраняются. Ошибки в mock — демонстрационные состояния, не ошибки приложения. Счётчик активных включает Working, Thinking, Reviewing и Testing.
