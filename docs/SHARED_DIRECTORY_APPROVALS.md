# Stable approvals for shared parent directories

Two independent, ready proposals may both include creating a missing parent directory. When the first proposal was approved, the second previously recomputed its operation list from current disk state and omitted that directory. Its IDs no longer matched the prepared approval, causing `Approval resources changed` despite an unchanged diff.

`TeamActions.requests(..., true)` reconstructs the original directory prerequisites from the permission ledger. It uses only records referenced by this approval and belonging to the same project, workflow, task and employee. Those parents remain in their original operation order even if they now exist. File requests and their patch digests are still regenerated and checked against their exact prepared records. Existing directories are safe prerequisites; no project file is rewritten because a parent exists.

Preparation continues to include only missing parents. Application and rejection use the retained original parents. A changed diff/path/scope, foreign ledger binding, expired approval, symlink/junction, non-directory parent or newly missing unapproved parent remains blocked. Completed receipts continue through the existing idempotent path, without reapplying earlier files. No permission policies, TTLs or automatic approvals were added.

Validation: 51 tests passed across `team-actions.test.mjs`, `permissions.test.mjs`, `security-http.test.mjs` and `team-workflow.test.ts`. New cases cover sequential confirmation across restart, nested shared directories, changed patch/path, replaced parent, a disappearing unapproved parent, rejection of the original full operation list and unchanged first-file timestamps on repeated receipt retrieval. TypeScript/Vite production build passed. The saved ARMGARAGE BookingDialog proposal also passed a read-only check against a memory copy of the permission ledger: original request IDs and original before-state match. No live proposal was applied, no project QA was rerun and no Codex job was started for this fix.
