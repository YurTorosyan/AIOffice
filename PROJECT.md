# AI Office

## Текущий Stage 3B

Установлены 12 проверенных community Skills, три кандидата не объявляются установленными. Один работник может иметь несколько Skills, общее назначение требует обоснования. Сохраняются восемь работников, восемь профилей, mock workflow, интерьер и анимации. Реальный runtime и дополнительные инструменты выполнения Skills не подключаются. Каталог с источниками, лицензиями, зависимостями и commits: docs/COMMUNITY_SKILLS_CATALOG.md. После завершения остановиться, следующий этап не начинать.

Самостоятельное локальное приложение, не связанное с MASIX. Владелец — Director, вне состава работников.

## Этап 1
Полноценный пиксельный офис, ровно 8 постоянных работников, собственные персонажи и рабочие места, восемь статусов, задачи, проект и Activity. Данные явно демонстрационные. Пауза и сброс симуляции, выбор сотрудника. После этапа остановиться для проверки владельцем.

React + TypeScript + Vite. Без backend, регистрации, облака и платных интеграций. Не используется код Agent Office / NosytLabs.

Запуск описан в README.md.

## Этап 2

Реализованы единая модель Agent State, отдельная модель задач, команды с проверкой переходов, внутренняя шина событий и последовательный mock workflow команды. Состав, интерьер, персонажи и существующие анимации сохранены. Ручная работа с задачами доступна в небольшом Task Panel. Реальный Codex не подключён; данные пока только в памяти. После проверки и коммита этапа 2 остановиться для владельца.

## Этап 3

Восемь оригинальных проектных Skills и восемь Custom Agent TOML-профилей связаны с существующими сотрудниками через единый реестр. В карточку добавлены основной Skill и ответственность. Состояние задач, события, mock workflow, интерьер и анимации сохранены; реальный runtime не подключается. После проверки, коммита и доступного push остановиться для владельца.
